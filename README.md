# Heshima Progressive Group Website

Responsive, mobile-first website for Heshima Progressive Group.

## Included
- Modern responsive design
- Heshima logo asset
- Mission and vision
- Focus areas
- Programs
- Impact section
- Gallery placeholders
- News section
- Membership/get-involved form
- WhatsApp-ready workflow
- SEO metadata
- GitHub Pages compatible

## Before launch
Replace the placeholder WhatsApp number in `js/script.js`, then add official phone, email, social links, real project photos, program details and other approved organizational information.

## GitHub Pages
Upload the repository contents, then use GitHub: Settings → Pages → Deploy from branch → main → / (root).
